Recetario C — Gestor y buscador de recetas WIP

2026 – Actualidad · Self-Hosted / PWA

Audio Streaming — Reproductor y biblioteca de música WIP

2026 – Actualidad · Full-Stack

Ecosistema full-stack para streaming de música y gestión de biblioteca personal en red privada (Tailscale/LAN), diseñado para reproducir audio fluido sin interrupciones en cualquier dispositivo.

  • Backend en Java 25 y Spring Boot 4 con streaming optimizado mediante cabeceras HTTP Range (206 Partial Content) para carga instantánea y buffering continuo.
  • Base de datos relacional PostgreSQL con migraciones versionadas mediante Flyway para catálogo de artistas, álbumes, pistas y carátulas.
  • Cliente web SPA en Angular 21 y TypeScript con reproductor persistente, cola de reproducción y diseño responsive con SCSS.
GitHub repo (Monorepo) Backend Frontend

Sistema de gestión de pedidos en restaurantes (Apúntame) WIP

Agosto 2025 – Actualidad · TFC / Full-Stack

Desarrollé Apúntame, un sistema de gestión de pedidos para un restaurante, como trabajo de fin de ciclo y en continua evolución. El objetivo es que tomar, procesar y ver las comandas en cocina y sala sea rápido e intuitivo.

  • El camarero registra el pedido y el servidor lo envía en tiempo real vía WebSockets/STOMP a las diferentes estaciones (cocina, barra, postres). Cuando una estación termina su parte, avisa al resto.
  • Funciona en local sin depender de internet: base de datos, lógica e interfaz en contenedores Docker.
  • Incluye gestión de usuarios con JWT, historial de pedidos, búsqueda de productos, ingredientes y alérgenos, y una interfaz adaptativa con Angular Material.
